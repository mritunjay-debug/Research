Pillar Case-History & Uncertainty Workbench

Prepare documented pillar records: map source columns, check completeness and physical plausibility, flag duplicate identifiers, normalize units, audit outcome labels and run transparent one-factor sensitivity scenarios.

Research integrity: no real case-history dataset is supplied. Import records with traceable sources and retain original values. Never infer observed failure labels from model predictions. Separate calibration from independent validation cases. Sensitivity outputs are conditional calculations—not failure probabilities or design approval.

Recommended research workflow

  1. Record the source, DOI/URL, mine, geology and original definition of failure/stability.
  2. Preserve raw data and document every unit conversion and label harmonization.
  3. Resolve duplicate IDs manually using source context; do not automatically delete them.
  4. Define inclusion/exclusion criteria before model evaluation.
  5. Group cases by mine/publication during data splitting to reduce leakage.
  6. Report sample size, class imbalance, missingness, exclusions, domain mismatch and uncertainty.
