Literature Search & PRISMA Screening

Search Crossref metadata, import database exports, deduplicate records, screen studies and maintain a transparent PRISMA-style flow summary. Export the study library and screening log to Excel or Word.

1. Search scholarly metadata

Searches Crossref's public metadata API. Results are not a comprehensive database search and citation counts are not a measure of study quality. For systematic reviews, also search the databases required by your protocol.

2. Import database exports

Import CSV, XLSX or RIS files exported from Scopus, Web of Science, PubMed or other reference managers. Original imported fields are retained where possible; map common title, author, year, DOI and abstract fields automatically.

3. Deduplicate and track screening

Deduplication prioritizes normalized DOI, then exact normalized title, then a conservative title-similarity check. Similar-title matches are flagged for confirmation rather than silently discarded. Screening decisions and reasons can be edited record by record.

Method and limitations

This is a screening aid, not a fully automated systematic review. Save your original database exports and search strings. Record databases, dates, filters, and protocol decisions for reproducibility. Metadata coverage varies; a missing DOI or abstract is not proof a paper is invalid. Similar-title deduplication is advisory and must be reviewed.
