Open-access paper downloads

Check Unpaywall's OA locations for records with a DOI, then download available full-text PDF links when their hosts permit browser access.

The ZIP contains a Python script that attempts to download only legally accessible open-access PDFs from recorded OA locations, plus a CSV manifest of successes and failures. Publisher permissions, anti-bot protections and network access may prevent some downloads. It does not bypass paywalls or access controls.

Save your work

Keep a working copy in this browser, restore it on the same browser/device, or export records in RIS format for use in Zotero, EndNote and other reference managers. Browser storage is not a cloud backup; export regularly.

About this tool and its limitations
This is a screening aid, not a fully automated systematic review. Save your original database exports and search strings. Record databases, dates, filters, and protocol decisions for reproducibility. Metadata coverage varies; a missing DOI or abstract is not proof a paper is invalid. Similar-title deduplication is advisory and must be reviewed.
