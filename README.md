# Research

## Citation Verification Agent
A Streamlit app for checking a DOCX reference list against Crossref, reviewing uncertain citations, and exporting Word and Excel reports.

- Application: [citation-verification-agent/app.py](citation-verification-agent/app.py)
- Setup and deployment: [citation-verification-agent/README.md](citation-verification-agent/README.md)
- Dependencies: [citation-verification-agent/requirements.txt](citation-verification-agent/requirements.txt)

To publish the app for free, deploy it on [Streamlit Community Cloud](https://share.streamlit.io/) with repository mritunjay-debug/Research, branch main, and main file path citation-verification-agent/app.py.
