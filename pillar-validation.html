Pillar Model Validation Bench

Compare model estimates against measured pillar strengths or observed case-history values. Import a CSV, map the observed and predicted columns, inspect paired records, and export reproducible validation metrics—all in this browser.

Important: this tool calculates agreement statistics; it does not establish that a model is valid or applicable. Use independent observations, document units and provenance, separate calibration from validation, and report sample size and limitations. Do not treat a high R² alone as proof of agreement or safe design.

Metric definitions

RMSE
√[Σ(predicted − observed)² / n]. Penalizes large errors more strongly.
MAE
Σ|predicted − observed| / n. Average absolute deviation.
Mean bias
Σ(predicted − observed) / n. Positive values indicate overprediction on average.
R²
1 − SSE/SST relative to the observed mean. Can be negative and is not an agreement statistic.
MAPE
Mean absolute percentage error. Not reported if any observed value is zero.
Scope
Use the same units for both columns. Report dataset source, split strategy, n, model domain, and uncertainty with published results.
